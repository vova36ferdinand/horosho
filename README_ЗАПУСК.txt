ЗАПУСК ПРОЕКТА

Откройте два окна командной строки в папке проекта.

1. В первом окне запустите сервер:

    py src/rpc_server.py

2. Оставьте сервер работающим. Во втором окне запустите Python-клиент:

    py client.py

Клиент выполнит все 13 операций задания на сервере и выведет результаты.
Python-код примера можно изменить в функции demonstrate файла client.py.
Команды запуска вводятся в C:\...>, а не в Python с приглашением >>>.

ДОПОЛНИТЕЛЬНЫЕ РЕЖИМЫ

run_rpc.bat открывает меню клиента, подключённое к серверу.
run_server.bat запускает сервер двойным щелчком.
run.bat выполняет тесты, показывает покрытие и открывает локальное меню.

PEP 8

Файлы Python отформатированы под стандартные ограничения PEP 8,
включая длину строк до 79 символов и отсутствие пробелов в конце строк.
Чтобы дополнительно проверить стиль, установите pycodestyle и выполните:

    py -m pycodestyle src tests

Проверка синтаксиса и тестовый RPC-запрос выполнены.
